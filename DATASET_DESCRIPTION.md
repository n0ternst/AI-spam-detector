# Описание размеченного датасета и схемы разметки (DW-1)

Датасет проекта состоит из двух частей: **текстового корпуса** (на базе `LLMTrace` для обучения и оценки текстового модуля `Qwen2.5-1.5B + CatBoost`) и **гибридного MIME/HTML корпуса** (для обучения и оценки детектора верстки `HTMLDetector`).

---

## 1. Текстовый корпус (на базе `LLMTrace`: Classification + Span Detection)

### 1.1. Источники и принцип разбиения
Корпус собран скриптом `build_llmtrace_dataset.py` (с фиксированным `seed=42`) из двух открытых веток датасета на HuggingFace:
* **`iitolstykh/LLMTrace_classification`** — для формирования сплитов бинарной классификации (`train`, `val`, `test`);
* **`iitolstykh/LLMTrace_detection`** — для формирования отложенного теста на частично сгенерированных текстах (`mixed_test`).

**Правила фильтрации и защиты от утечки данных:**
* Для классификации отбираются тексты длиной $\ge 60$ символов (`len(text.strip()) >= 60`).
* Для теста смешанных текстов отбираются записи с меткой `mixed`, непустым списком интервалов `ai_char_intervals` и длиной $> 150$ символов.
* С помощью множества `used_topics` гарантируется **строгое непересечение идентификаторов тем (`topic_id`)** между выборками `train`, `val` и `test`.

### 1.4. Схема разметки текстового корпуса (JSONL)

1. **Файлы классификации (`raw_train.jsonl`, `raw_val.jsonl`, `raw_test.jsonl`):**
   Каждая строка представляет собой JSON-объект со следующими полями:
   * `text` (`string`): текст документа;
   * `label` (`string`): целевая метка — `"human"` (текст человека) или `"ai"` (сгенерировано ИИ);
   * `lang` (`string`): язык текста — `"ru"` или `"eng"`;
   * `data_type` (`string`): домен/жанр текста (`article`, `news`, `question`, `review`, `story`, `poetry` и др.);
   * `model` (`string`): идентификатор языковой модели-генератора (или пустая строка для `"human"`);
   * `topic_id` (`string`): уникальный идентификатор темы (для контроля отсутствия утечек между сплитами).

2. **Файл локализации фрагментов (`raw_mixed_test.jsonl`):**
   Каждая строка представляет собой JSON-объект с разметкой частичной генерации:
   * `text` (`string`): текст со смешанным авторством;
   * `lang` (`string`): язык текста — `"ru"` или `"eng"`;
   * `label` (`string`): `"mixed"`;
   * `ai_char_intervals` (`list`): список символьных интервалов `[start_char, end_char]`, размечающих сгенерированные ИИ участки внутри текста;
   * `prompt_type` (`string`): тип промпта генерации;
   * `model` (`string`): модель-генератор.

## 2. Гибридный MIME/HTML корпус (для модуля `HTMLDetector`)

### 2.1. Источники и метод сборки
В связи с отсутствием открытых почтовых баз, содержащих одновременно подлинную HTML-верстку писем и современные LLM-генерации, корпус объёмом **4 000 HTML-писем** собран методом **DOM-трансплантации** (пересадки текстов в реальные почтовые каркасы):
* **Донор HTML-каркасов:** реальные сырые MIME-письма `Apache SpamAssassin Public Corpus` (`easy_ham` и `spam_2`) + адаптивные шаблоны верстки (`MJML`, `Gmail quote`).
* **Донор текстового наполнения:** парные ответы людей и языковых моделей из корпуса `Hello-SimpleAI/HC3` (человеческие тексты предварительно очищены от форумной разметки Reddit `**`).

### 2.2. Схема разметки и сценарии (50% Human / 50% AI)

| Класс (`label`) | Сценарий | Количество | Доля | Описание |
| :---: | :--- | :---: | :---: | :--- |
| **`0` (Человек)** | Оригинальные MIME-письма (`SpamAssassin`) | 800 | 20.0% | Нетронутые реальные HTML-письма |
| **`0` (Человек)** | Реальный DOM + текст `HC3` (с шумом) | 1 200 | 30.0% | Пересаженный текст человека; добавлен бытовой шум (10% — теги Google Docs `docs-internal-guid`, 20% — списки разной длины) |
| **`1` (ИИ-Спам)** | Чистая API-пересадка текста | 500 | 12.5% | Текст LLM в реальном шаблоне без HTML-маркеров и скрытых блоков |
| **`1` (ИИ-Спам)** | Утечки Markdown и типографики | 500 | 12.5% | Нераспарсенные маркеры `**жирный**`, `##` и повышенная плотность тире `—` / кавычек `“”` |
| **`1` (ИИ-Спам)** | Копипаст из браузера (ChatGPT / Claude) | 500 | 12.5% | Следы буфера обмена (`Söhne`, `--tw-`, `font-claude-message`, равномерные списки `<li><strong>`) |
| **`1` (ИИ-Спам)** | Стелс-клоакинг и Prompt Injection | 500 | 12.5% | Скрытые блоки (`font-size: 0px`, `display: none`, контраст WCAG < 1.3, сдвиг `-9999px`), инструкции обхода LLM, `\u200b`, гомоглифы `xn--` |

### 2.3. Разбиение HTML-корпуса и схема CSV
Разбиение выполнено со стратификацией по классам (`train_test_split`, `random_state=42`, пропорция **70% / 15% / 15%**):
* **`train.csv`:** 2 800 писем;
* **`val.csv`:** 600 писем (используется для подбора базового порога по $F_{0.5}$);
* **`test.csv`:** 600 писем (закрытый замер финальных метрик).

Каждая строка CSV-файлов содержит целевую бинарную метку `label` (`0` или `1`) и 46 числовых криминалистических признаков DOM-дерева (следы буфера обмена ИИ, ритмика абзацев/предложений/списков, легаси-атрибуты Outlook/ESP, топология и энтропия тегов, метрики визуального сокрытия и анти-фишинга).
